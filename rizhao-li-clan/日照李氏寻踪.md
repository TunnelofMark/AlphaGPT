# 日照李氏寻踪

> 调研范围：今日照市境内，日照太平桥李氏（又称学士李、石盖子李）的现存足迹。  
> 不限于李时勉—李永培—李簠—李应廌四世。  
> 整理时间：2026-09-01。  
> 说明：实体牌坊、祠堂、祖坟大多已不存；今日可核对的主要是老城街巷、奎山方位、字辈村落和馆藏谱牒。

## 1. 先把对象说清

本次寻踪的对象是 **日照太平桥李氏**，不是日照境内所有李姓。

- **始迁祖**：李士禧。明初洪武年间自山东临朐柳山寨迁至日照县城西门外太平桥附近。
- **别称**：太平桥李、学士李（因七世李应廌官至内阁学士）、石盖子李。
- **上源**：谱载出自临朐柳山李氏，奉李永贵为柳山始迁祖。李秀四子分徙：
  - 李士祯 → 安丘峰山李氏
  - 李士禄 → 寿光稻田李氏
  - 李士祥 → 沈阳桃园李氏
  - **李士禧 → 日照太平桥李氏**
- 日照城里姓李的人很多，并不都是这一支。例如东港区后村镇大代疃李氏，谱载来自江苏东海戴村，应分开看待。

### 1.1 与本次寻踪直接相关的四世（背景，非全部范围）

| 世代 | 人物 | 身份要点 |
|---|---|---|
| 太平桥四世 | 李时勉，号小泉 | 廪生。地方材料称家贫好学，有联“尺室斗来大，寸心天样宽”。后因曾孙显贵获追赠。 |
| 五世 | 李永培，字中阳 | 岁贡。青城教谕、胶东任职、陕西巩昌府教授。祀乡贤。光绪《日照县志》列入古墓。 |
| 六世 | 李簠，字宗周，号孝阳 | 顺治辛卯举人。蓬莱教谕、安东卫教授、江西浮梁知县。晚年把旧谱牒交给李应廌编次。 |
| 七世 | 李应廌，字谏臣 / 柱三，号愚庵 | 康熙十五年进士。翰林编修、《明史》纂修、顺天学政、内阁学士兼礼部侍郎。张英为《日照李氏族谱》作序；张玉书为其撰墓志铭，记葬于聚奎山之阳。 |

张英《日照李氏族谱序》收入《文端集》卷四十。李应廌墓志铭作者是张玉书，不是张廷玉。

## 2. 结论先看

日照李氏在城里的脚印，今天主要剩三条线：

1. **正阳路老城**：太平桥开基地带、“四世一品”坊旧址、“李半城”所指街区。
2. **兴安街文庙旧址**：乡贤祠所在的日照文庙，今为东港区第一小学。
3. **开发区奎山**：即旧志聚奎山。李应廌葬“聚奎山之阳”；李永培墓亦入县志。山还在，坟多半已迁。

活着的族人，则散在东港老城周边、南湖、西湖，并延伸到岚山安东卫、巨峰以及五莲南部。识别这一支最管用的是自 13 世起的派语，而不是只认一个“李”字。

## 3. 老城核心：正阳路—望海路口

今日照 **东港区日照街道** 旧城十字一带，是日照李氏在城里最密的一块。

### 3.1 太平桥旧址

- 明代西门称太平门，门外石桥称太平桥。李、张两姓世居桥旁，因此才有“太平桥李”“太平桥张”。
- 嘉靖时县城向西扩展，西门改为振武门，太平桥顺延入城，河道逐渐填平，十字街仍沿用太平桥之名。
- 康熙七年大地震后，知县佟国瓒在旧太平门处建太平楼。
- 地方考证把旧桥对到 **今日照百货大楼以西、原人民商场以东**，大约是 **正阳路 46 号日照百货大楼西侧** 一带。另有一说旧太平门/桥在今武装部与日照银行交界、移动营业厅附近。
- **现状**：桥本身已不存，能走的是这条老街。

### 3.2 “四世一品”石牌坊旧址

- 康熙三十四年（1695）官方为李应廌家族修建。
- 日照新闻网：位于原日照县衙西，即现在日照市中医医院东侧的正阳路上，自南向北排列；横匾“四世一品”据载为康熙御笔。
- 另一地方考证：在今工人文化宫西边官道上。
- 这几处今天仍挤在同一路口：
  - 日照市中医医院：望海路 35 号
  - 工人文化宫：望海路与正阳路交叉口东约 60 米
  - 百货大楼：正阳路 46 号
- 旧城北门拱极门，志书对在正阳路北段、中医医院东北隅墙外。
- **现状**：1966 年文革拆除，地面上看不到坊柱。这是目前对得最准的一处“学士李”坐标。

### 3.3 “李半城”

族谱和地方材料说这一支后来科甲、田产很盛，时人称为“李半城”。这不是今天的地名，而是说旧城里李家产业很多。走正阳路、旧县衙到西门这一带，就是当年这个说法所指的范围。

## 4. 乡贤祠与文庙

- 李永培、李应廌都被祀入日照乡贤祠。
- 乡贤祠在文庙戟门西侧（东为名宦祠，西为乡贤祠）。
- 日照文庙：元至正十一年（1351）县尹仇敬创建于县署西南；明嘉靖三十六年（1557）迁东门外。
- 今日对应：**日照市东港区第一小学（城关一小）**，地址 **兴安街 29 号**，在苏宁广场、海曲中路附近。
- 1948 年学校迁进文庙，1964 年大成殿拆除，原建筑已不存。
- 这里能确认的是 **祀典地点**，不是还能看到牌位。

李簠做过 **安东卫教授**。安东卫今属 **岚山区安东卫街道**，那是他的任职地；1977 年《山东日照李氏在台联谱》也把“安东卫”列为后裔支分之一。

## 5. 聚奎山 / 奎山

- 张玉书《愚庵李公墓志铭》写李应廌葬于 **聚奎山之阳**。
- 康熙《日照县志·山川》：“聚奎山郡志曰孤奎山，通志曰奎山，在城南十七里，为县之文笔峰。”
- 光绪《日照县志》：“奎山省志作圭山，旧志作聚奎山……县南十五里，三峰如笔架。”并在古迹/古墓中列入 **李永培墓**。
- 山南原有明建玉皇殿、聚奎庙，文革中毁。
- 今天这座山在 **日照经济技术开发区奎山街道** 南侧。2004 年起按“封山、绿化、迁坟、开发”封闭多年，山周坟墓大多已迁走。近年在建奎山山地公园和奎山体育中心。
- **判断**：山还在，南坡方位也对得上“聚奎山之阳”；原坟、原庙基本可以判断已经不在原地。去奎山是看家族选择的风水山，不是去找完整墓园。

## 6. 岚山巨峰辛留村：单独标疑

一些地方文章和百科写李应廌“生于日照城太平桥（巨峰镇辛留村）”。辛留村今属 **岚山区巨峰镇**，在镇政府西北约 5 公里。

- “日照城太平桥人”有县志、履历、族谱支撑。
- 把出生地直接写成辛留村，目前更像后来地方文章的叠加，**证据弱于老城太平桥**。
- 更稳妥的理解：辛留一带可能有这一支后来的聚居或分支，值得去问字辈和老谱，但不宜先当成李应廌出生地。

## 7. 现在还能找到后裔的村子

实体牌坊、祠堂、祖坟大多没了，**人还在**。识别这一支最管用的是自 13 世起的派语：

```
为予衍其绪，宗业宜慎守；
忠厚作贻谋，家运乃克久；
植基资笃信，敦行尚朴诚；
敬共存世泽，懿训栽心铭。
```

个别用字会有“资/兹”“共/恭”“栽/载”之差，主干一致。

### 7.1 已对上这套字辈的村子

| 今行政区 | 村子 | 把握 |
|---|---|---|
| 东港区日照街道 | 后山前村 | 高。公开字辈汇编直接对应 |
| 东港区南湖镇 | 相家官庄村 | 高。同上 |

### 7.2 1977 年《山东日照李氏在台联谱》列出的支分地名

山口村、马庄、石桥、黄山前、安东卫、下湖、潘家村。

今日照市内能找到对应村子，但同名很多，不能一村定一支：

| 联谱地名 | 今日照可能对应 | 备注 |
|---|---|---|
| 山口 | 东港区卧龙山街道山口村；岚山区中楼镇山口村 | 两处同名，需用字辈核 |
| 黄山前 | 东港区南湖镇东 / 中 / 西黄山前村 | 与相家官庄同镇，较值得先问 |
| 下湖 | 东港区南湖镇下湖一 / 二 / 三村 | 同上 |
| 石桥 | 东港区日照街道大石桥村；西湖镇石桥官庄村 | 同名，需核 |
| 马庄 | 东港区西湖镇前 / 后马庄 | 需核 |
| 安东卫 | 岚山区安东卫街道 | 李簠曾任安东卫教授；联谱亦列此支 |
| 潘家村 | 岚山一带有潘家村 | 是否即联谱所指，还要用字辈核 |

诸城李氏考证还写：这一支 **广泛分布在日照及五莲南部街头一带**。五莲街头镇值得按同一套派语去问，不是只看老城。

到村里最有效的问法：

1. 家里是否认 **太平桥李 / 学士李 / 石盖子李**
2. 派语是否从“为、予、衍、其、绪”起
3. 老辈是否还记得李应廌、四世一品坊

地方公众号“海曲风韵”做过纪录片《寻找清代大学士李应廌》，里面可能有后人采访和旧址画面。

大连捐谱事件原始报道为 2015 年 7 月 7 日《半岛晨报》，记者齐芳芳，题《日照李氏望族后人捐赠族谱》。报道把李应廌写成“内阁大学士兼礼部侍郎”不准确，正式官职是 **内阁学士兼礼部侍郎**。捐谱事实本身可信度较高。

## 9. 去日照怎么走

### 半天：只走老城

1. 正阳路 46 号百货大楼西侧：太平桥、李氏开基地带
2. 望海路与正阳路口：中医院东、文化宫西，四世一品坊旧址
3. 兴安街 29 号东港一小：文庙、乡贤祠旧址

### 加半天：看山

奎山山地公园 / 奎山街道，对应聚奎山。山在，坟多半已迁。

### 要找活人

- **优先**：日照街道后山前村、南湖镇相家官庄
- **再扩**：南湖镇黄山前、下湖；西湖镇马庄、石桥官庄；岚山安东卫、巨峰辛留；五莲街头
- **口令**：上面四句派语

### 进馆

- 市博物馆问历史名人厅
- 市 / 区档案馆问太平桥李谱和牌坊档案
- 若要看实体谱，大连沙河口区档案馆那一部是目前已知还在馆里的本子

## 10. 不要和别的日照李氏混在一起

日照至少还有其他李姓来源：

- 东港区后村镇 **大代疃** 李氏：谱载来自江苏东海戴村，1990 年有《山东日照东港区李氏族录》
- 莒县、五莲另有多支李氏，字辈不同

认人认谱，认的是 **太平桥 / 学士李 / 石盖子李** 和那套派语。

## 12. 仍待核实

1. 大连沙河口区档案馆藏《日照李氏族谱》的馆藏号、修谱年代、卷首是否有张英《日照李氏族谱序》。
2. 李永培墓、李应廌墓迁葬后的现址。
3. 在台联谱各支分村，哪些至今仍用“为予衍其绪”派语。
4. 日照市博物馆历史名人厅是否收录李应廌。
5. 辛留村李姓与太平桥李的实际世系关系。
6. 李应廌、李簠在日照所置义田的地亩与位置。《山东通志》记李应廌“克承父志，增广义田”；县志另记他在通州一带置义田，日照本地义田细址未找到。

## 一句话

日照李氏在城里的脚印，今天主要剩三条线——**正阳路老城（桥、坊、半城）**、**兴安街文庙旧址（乡贤）**、**开发区奎山（聚奎山之阳）**；活着的族人，则散在东港老城周边、南湖、西湖，并延伸到岚山安东卫、巨峰以及五莲南部。牌坊和祖坟基本没了，街、山和字辈还在。
